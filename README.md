# RealSchoolHub

Материалы волонтёрской программы по разработке — Real School, отделение Ванадзора.

Цель: научить студентов реальным методологиям и инструментам разработки на примере настоящих
проектов, проведённых по полному циклу — от идеи до деплоя и поддержки.

## Параметры программы

| | |
|---|---|
| Срок | 8 недель |
| Студентов | 12 → 3 команды по 4 |
| Организация на GitHub | [`RealSchoolPool`](https://github.com/RealSchoolPool) |
| Стек | Python, C++ |
| Прод | школьный сервер |
