## 4. Проверка

## 5. Самопроверка по фильтру

Отметь честно:

- [ ] Есть живой пользователь, которого можно позвать в класс
- [ ] Первая версия реально влезает в две недели
- [ ] Делается на Python, работает на школьном сервере
- [ ] Не требует персональных данных учеников
- [ ] Не требует денег
- [ ] Понятно, как измерить результат
