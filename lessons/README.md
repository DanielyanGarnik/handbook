# Задания и проверка

Здесь лежат задания и скрипт, который их проверяет. Ничего устанавливать не нужно —
хватит того Python, который уже стоит на машине.

**Если не знаешь, с чего начать, — читай [HOWTO.md](HOWTO.md).** Там разобрано по шагам,
как писать программу и как читать ошибки.

## Как пользоваться

**Посмотреть список заданий и свой прогресс:**

```
python check.py
```

**Решить задание.** Создай рядом с `check.py` файл с именем задания — для `task01`
это `task01.py` — и напиши решение внутри.

**Проверить:**

```
python check.py task01
```

Скрипт запустит твою программу на нескольких примерах, сравнит вывод с ожидаемым,
посмотрит на оформление кода и скажет, что не так.

## Что важно знать

**Попытки не отнимают баллов.** Их вообще никто не считает против тебя — счётчик нужен только
для того, чтобы подсказки становились конкретнее. Первые две попытки скрипт показывает только
расхождение, дальше начинает намекать, а к пятой говорит прямо.

**Программа должна печатать только ответ.** Никаких «Введи имя:» — если написать
`input("Введи имя: ")`, эта подсказка тоже попадёт в вывод, и проверка не сойдётся.
Пиши просто `input()`. Это не придирка: программу, которая печатает лишнее, нельзя
подставить в конвейер и нельзя проверить автоматически.

**Замечания по коду — не ошибка.** Если все примеры прошли, задание засчитано, даже когда
внизу есть замечания. Но на ревью их всё равно попросят поправить, так что лучше сразу.

**Ошибку Python нужно читать, а не пугаться.** Скрипт печатает её целиком. Самая важная
строка — последняя, а номер строки над ней говорит, где смотреть.

## Если застрял

Порядок такой: перечитай критерии приёмки → посмотри на расхождение, которое показал скрипт →
запусти ещё раз и прочитай подсказку → спроси соседа → спроси преподавателя.

Пятая попытка подряд без прогресса — это сигнал не сидеть молча, а спросить. Объяснить вслух,
что должно происходить, — работает чаще, чем ещё полчаса смотреть в экран.

## Файлы

```
lessons/
├── check.py          проверяльщик — его менять не нужно
├── tasks/            задания в JSON, можно открыть и почитать
├── task01.py         сюда пишешь ты
└── .progress.json    твой прогресс, создаётся сам
```
